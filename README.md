# Telegram 双向客服机器人

包含双向客服消息、首次启动自动管理员、广播、客服名单、会话结束/重开、黑名单、用户统计和 JSON 持久化。

## 部署

需要 Node.js 20 或更高版本。配置环境变量 `BOT_TOKEN` 后运行 `npm start`。请使用持久化磁盘保存 `DATA_DIR`，否则平台重新部署后本地 JSON 数据可能丢失。

`ADMIN_ID` 可选。若留空，首次私聊机器人并发送 `/start` 的账号会成为管理员。请确保你本人先启动，避免其他人抢先成为管理员。不要把 Token 写进仓库。

## 广播

管理员私聊机器人发送 `/broadcast`，然后发送一条广播内容。支持文字、图片、视频、文件等单条消息；发送 `/cancel` 可取消。广播只发送给曾经启动并联系过机器人的登记用户，Telegram 不允许机器人主动联系从未启动过它的用户。

## 常用命令

- `/users`：用户统计
- `/agents`：查看客服名单
- `/addagent 用户ID`、`/delagent 用户ID`：管理客服
- `/blacklist 用户ID`、`/unblacklist 用户ID`：黑名单管理
- `/end 用户ID`、`/open 用户ID`：结束或重开会话

用户发来的消息会复制给管理员。管理员直接回复被复制的用户消息，机器人会把回复复制回原用户。广播逐个发送并统计成功/失败；大规模广播会受 Telegram 速率限制。

## 上线前测试

先用管理员账号和一个测试账号验证文字、图片、回复、广播和重启后数据是否保留。当前基础版本将客服通知发到管理员私聊；`SUPPORT_GROUP_ID` 适用于将新消息投递到群，但群内回复流程仍需在正式使用前单独验证。
